# Module 1 Assignment: Highridge Construction Company Payment Slips

## Overview
The purpose of the assignment is to develop a Python (and R) program to facilitate weekly payment of workers.

The program dynamically generates a list of 400 workers, assign some attributes and then conditionally assigns salary levels depending on each worker's salary amount and sex.

## Files
- `assignment1.py`: Main program.
- `assignment1.py`: Equivalent R program.

## Requirements
- Python 3.x and any current version of R
- Required packages: Both Python and R have base modules containing functions for generating random values

## How to Run
- Open Python or R script in any supported IDE and execute e.g Spyder for Python and Rstudio for R (or just RGui)

## Results
- The program will generate a list of 400 workers dynamically, each with id, name, age, sex, department, salary, and salary level (created conditionally using salary and sex). 
- It will finally print the text "Payment slips generated successfully for all workers."
